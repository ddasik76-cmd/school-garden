# 텃밭 기후 탐구노트

중학생이 텃밭 작물의 성장과 날씨를 함께 기록하며 기후·생태 탐구를 할 수 있도록 만든 서버리스 웹앱입니다.

## 핵심 특징

- 로그인 없음
- 별도 데이터베이스 없음
- 텍스트/설정/관찰/성찰: 브라우저 `localStorage`
- 사진: 브라우저 `IndexedDB`
- 카메라 직접 촬영 / 기기 앨범 사진 선택
- 모바일 호환성을 높인 사진 자동 리사이즈/압축
- IndexedDB 저장 직후 사진 저장 검증
- 가능한 브라우저에서 영구 저장소(persistent storage) 요청
- 날짜별 기상 데이터 자동 입력
- 작물 성장 + 기상 데이터 그래프
- 새싹 포인트 / 탐구 레벨 / 배지 / 오늘의 미션
- ZIP 한 파일로 전체 데이터 + 사진 백업/복원
- 한 학기 텃밭 탐구보고서 PDF 생성
- 모바일/PC 반응형
- PWA 기본 지원

## 날씨 데이터

현재 버전은 **Open-Meteo**를 사용합니다. 별도 API 키가 없어 GitHub Pages에서 바로 작동합니다.

전송되는 정보:
- 설정한 위도/경도
- 조회 날짜

전송하지 않는 정보:
- 학생 이름/별칭
- 사진
- 관찰 기록
- 성찰 기록

기상청 공식 API로 바꾸려면 `index.html`의 `fetchWeather()` 함수만 교체하면 됩니다. API 키를 사용한다면 HTML에 직접 넣지 말고 서버리스 프록시를 두는 것을 권장합니다.

## GitHub Pages 배포

1. 새 GitHub 저장소 생성
2. 이 폴더의 파일 3개를 저장소 루트에 업로드
   - `index.html`
   - `manifest.webmanifest`
   - `service-worker.js`
3. GitHub 저장소 → `Settings` → `Pages`
4. `Deploy from a branch`
5. Branch `main`, Folder `/ (root)` 선택 후 Save
6. 생성된 GitHub Pages 주소 접속

## ZIP 백업/복원

`보고서 → ZIP 백업`을 누르면 아래 구조의 파일이 생성됩니다.

```text
garden-backup-YYYY-MM-DD.zip
├─ data.json
├─ README.txt
└─ photos/
   ├─ photo_xxx.jpg
   └─ ...
```

새 기기에서는 ZIP을 풀지 말고 앱의 `ZIP 복원`에서 **ZIP 파일 그대로** 선택합니다.

복원 시 현재 기기의 텃밭 데이터는 지우고 백업 상태로 완전히 복원됩니다.

## PDF

`보고서 → PDF 보고서 다운로드`에서 현재 기록을 이미지 기반 PDF로 생성합니다.
한글 폰트 파일을 서버로 전송하지 않아도 되도록 화면을 렌더링해 PDF로 저장하는 방식입니다.

## 주의

브라우저의 사이트 데이터/캐시를 직접 삭제하면 저장 데이터가 사라질 수 있습니다.
학생들에게 1~2주 간격으로 ZIP 백업을 안내하는 것을 권장합니다.

## 외부 라이브러리

CDN:
- Chart.js
- JSZip

- jsPDF

## v1.1.0 사진 저장 개선

- `createImageBitmap()` 단독 의존을 제거하고 HTML Image 기반 fallback을 추가했습니다.
- 모바일에서 카메라 촬영과 갤러리 선택을 별도 버튼으로 제공합니다.
- 사진 저장 후 IndexedDB에서 실제 Blob이 읽히는지 검증합니다.
- 서비스워커 캐시 버전을 올리고 HTML은 network-first로 변경하여 GitHub Pages 업데이트가 더 빨리 반영됩니다.
- 앱 내부 개인정보 처리 안내와 사진 촬영 주의사항을 강화했습니다.


## 개인정보 안내

앱의 데이터 처리 구조와 외부 서비스 관련 설명은 `PRIVACY.md`에 정리되어 있습니다. 학교 적용 전 실제 운영 환경과 학교 지침에 맞춰 검토하세요.


## v1.3.0 A4 탐구보고서 개선

- 보고서 페이지를 실제 A4 세로 비율로 고정했습니다.
- 본문 글자 크기는 인쇄 기준 약 10~12pt 수준으로 구성했습니다.
- 긴 화면을 임의로 잘라 PDF로 만드는 방식 대신, A4 페이지별로 렌더링하여 페이지 중간 잘림을 줄였습니다.
- 저장된 전체 관찰 데이터를 날짜별 표로 출력합니다.
- 각 관찰 행에 사진 썸네일, 성장 측정값, 평균기온·강수·일조, 관찰 및 날씨 관련 생각을 함께 출력합니다.
- 첫 관찰과 최근 관찰 사진을 비교해 출력합니다.
- 작물 키·평균기온·강수량을 함께 보여주는 성장 그래프를 보고서에 포함합니다.
- 저장된 성찰 기록을 별도 A4 페이지에 정리합니다.
- PDF 다운로드 외에 브라우저의 A4 인쇄 기능을 추가했습니다.


## v1.3 사진 비율 수정

- A4 보고서의 첫/최근 비교 사진을 4:3 프레임으로 표시합니다.
- 사진은 `object-fit: contain`으로 원본 비율을 유지하며 좌우로 늘어나지 않습니다.
- 날짜별 관찰표의 썸네일도 원본 비율을 유지합니다.


## v1.5.0 범용 지역 설정 및 에듀집용 개인정보 안내 개선

- 특정 지역(충남 서산시)을 기본값으로 사용하지 않습니다.
- 학생/교사가 지역명을 직접 입력하고 `지역 찾기`를 눌러 Open‑Meteo Geocoding으로 날씨 조회 좌표를 설정합니다.
- 개인 기기의 현재 위치(GPS)는 요청하거나 사용하지 않습니다.
- 기존 v1.3에서 자동으로 들어 있던 서산 기본 좌표는 사용자가 직접 확정한 위치로 보지 않고 비웁니다.
- 개인정보 처리방침을 제1조~제11조 구조의 상세 모달로 재구성했습니다.
- 개인정보 처리방침에 기기 저장, 외부 서비스, 만 14세 미만 이용, 삭제/복원, 안전성 확보, 문의처를 명시했습니다.
- 대시보드 하단에 개발자 정보와 데이터 보관/백업 안내를 작은 글씨로 추가했습니다.
